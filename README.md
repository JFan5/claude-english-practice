# claude-english-practice

一个 Claude Code skill，用于**中译英口语翻译练习**。

Claude 会出一段中文，你口语翻译并把英文文本发给它。Claude 从**准确性 / 流畅度 / 语法 / 用词**四个维度打分（满分 100）。

> **未过设定阈值必须重复同一段，直到通过或达到最大重试次数为止。**

---

## 工作流

每个新会话开始时，Claude 会先确认三个参数：

| 参数 | 默认值 | 说明 |
|------|-------|------|
| 通过阈值 | 80 | 多少分算过 |
| 最大重试次数 | 3 | 同一段最多重试几次 |
| 难度 | 中等 | 简单 / 中等 / 困难 |

回复 `用默认` 或自定义如 `85 / 5 / 困难` 即可。

之后流程：

1. Claude 出一段中文（按确认的难度）
2. 你口语翻译，把文本发给 Claude
3. Claude 打分（含分项得分和点评）
4. **未过阈值** → 不给参考译文，重试同一段
5. **过了阈值** → 给参考译文 + 重点提升点 + 进步亮点
6. **达到最大重试次数仍未过** → 给参考译文，进入下一段

## 安装

### 方式 1：clone 到本地 skills 目录

```bash
git clone https://github.com/JFan5/claude-english-practice.git ~/.claude/skills/english-practice
```

### 方式 2：手动复制

把 `SKILL.md` 放到：

```
~/.claude/skills/english-practice/SKILL.md
```

> ⚠️ 文件名**必须**是 `SKILL.md`，Claude Code 才能识别。文件夹名随意。

---

## 使用

安装后重启 Claude Code（或开新会话），然后任意一句话触发即可，例如：

- 「我们来练英语翻译」
- 「我说一段中文你翻译」
- 「开始 english practice」

也可以直接说 **"按 english-practice 规则练一段"**。

---

## 评分维度（每项 25 分）

| 维度 | 看什么 |
|------|--------|
| 准确性 | 关键词是否到位、有无漏译误译 |
| 流畅度 | 是否一气呵成，自我修正/卡顿次数 |
| 语法 | 冠词、时态、主谓一致、动词形式 |
| 用词 | 搭配是否地道，是否避免中式英语 |

口语场景下流畅度标准会**适度放宽**，但准确性和语法按书面标准。
